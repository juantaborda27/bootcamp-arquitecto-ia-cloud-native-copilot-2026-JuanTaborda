# Crear un ADR

Decisión recibida: $ARGUMENTS

1. Lee `AGENTS.md`, el contexto técnico y ADR existentes para conservar formato y numeración.
2. Separa la necesidad de la solución preferida; identifica restricciones verificables.
3. Compara de dos a cuatro opciones con criterios pertinentes: complejidad, costo, seguridad, operación, portabilidad y capacidades del equipo.
4. Registra estado, fecha, contexto, decisión, alternativas, consecuencias positivas, consecuencias negativas y señales para reconsiderarla.
5. Vincula evidencia o mediciones disponibles. Marca supuestos no verificados.
6. Evita justificar una tecnología solo porque ya aparece en el bootcamp.
7. Revisa que la decisión sea coherente con el flujo E2E y el despliegue independiente.

Entrega un ADR conciso y un listado separado de validaciones pendientes.
