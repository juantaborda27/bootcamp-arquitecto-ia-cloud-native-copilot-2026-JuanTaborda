# Angular 22.1

Angular 22 es la major Active del bootcamp. Angular 21 continúa en LTS, pero no es la ruta principal para proyectos nuevos.

## Capacidades clave

- Signals y arquitectura standalone como base.
- Formularios reactivos, routing, guards e interceptors.
- SSR/hydration cuando el caso de uso lo justifique.
- Tooling y migraciones oficiales mediante `ng update`.

## Paso a paso

1. Crear componente con Signals, tabla y formulario reactivo.
2. Integrar backend, manejo uniforme de errores y guard de ruta.
3. Ejecutar build y pruebas con la versión generada por Angular CLI 22.
