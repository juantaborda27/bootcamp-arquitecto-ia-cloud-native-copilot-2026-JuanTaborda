# Tecnologías de datos

- `postgres.md`, `redis.md`: usados por los labs del núcleo (persistencia, caché y mensajería).
- `oracle.md`: Oracle XE contenerizado, requerido por el Lab 28 y electivo en el integrador.
- `mongo.md`, `sqlserver.md`: material de especialización para experimentar con un motor alterno.

La selección de motor debe responder al proyecto y quedar registrada en un ADR. El integrador requiere una base principal bien implementada, no todas las bases simultáneamente.
