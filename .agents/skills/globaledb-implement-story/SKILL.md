# Implementar una Historia (Global EDB)

Sigue este procedimiento paso a paso para desarrollar una feature o laboratorio:

1. **Lectura:** Lee [`AGENTS.md`](file:///c:/Users/DT/Desktop/Bootcamp_E/Bootcamp/AGENTS.md), la especificación de la historia/laboratorio y los archivos fuente relevantes.
2. **Criterios de Aceptación:** Define criterios de aceptación observables y explicita lo que queda fuera de alcance.
3. **Hipótesis y Prueba:** Formula una hipótesis sobre el cambio y el comando de prueba que podría refutarla.
4. **Plan:** Presenta un plan breve (máximo 8 pasos). Clarifica decisiones bloqueantes si las hubiera.
5. **Implementación Capa por Capa:** Avanza progresivamente por contrato/dominio, backend, cliente y operaciones.
6. **Validación Estrecha:** Tras cada edición relevante, ejecuta la prueba más estrecha. Si falla, corrige la misma capa antes de ampliar el alcance.
7. **Calidad y Seguridad:** Revisa autenticación, autorización, validación de entradas, manejo de errores, secretos, migraciones, idempotencia y observabilidad.
8. **Evidencia:** Presenta el resumen de cambios por archivo, comandos ejecutados, salidas reales, ajustes manuales y riesgos pendientes.
