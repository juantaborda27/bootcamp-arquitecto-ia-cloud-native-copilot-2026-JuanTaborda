# Evidencias detalladas

Esta carpeta almacena artefactos de apoyo por laboratorio. El índice y resumen obligatorio permanecen en `EVIDENCIAS.md` en la raíz.

Crea una carpeta por práctica:

```text
labs/evidencias/
  lab-01-ia-desarrollo/
  lab-19-nestjs/
  lab-99-integrador/
```

Admite Markdown, imágenes sanitizadas, salidas de comandos y reportes exportados. No almacenes secretos, tokens, archivos `.env`, datos personales, dumps de clientes ni logs sin revisar.

Usa nombres descriptivos y referencias relativas desde `EVIDENCIAS.md`. Evita PDFs o capturas cuando una salida textual reproducible sea suficiente.
